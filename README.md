# 🎙️ Whisper PTT (Push-to-Talk)

> Быстрый и полностью автономный голосовой ввод (распознавание речи) прямо в любое активное окно Windows. Аналог blabby.ai / Wispr Flow, но работает **локально на вашей видеокарте, без интернета, без подписок и с нулевой задержкой**.

---

## 🚀 Как пользоваться (Быстрый старт)

### 1. Запуск
Дважды кликните по файлу **`start.vbs`** (или его ярлыку). 
* В трее (возле часов) появится иконка микрофона.
* **Жёлтая иконка** — модель загружается в видеопамять (при наведении мыши виден прогресс `%`).
* **Зелёная иконка** (`Whisper PTT — ready (f9)`) — программа готова к работе.

### 2. Диктовка текста
1. Поставьте курсор в любое текстовое поле (в Telegram, браузере, коде, документе Word, блокноте).
2. **Зажмите клавишу `F9`** и говорите. Иконка станет красной (идёт запись).
3. **Отпустите `F9`** — прозвучит тихий звуковой сигнал (`ready.mp3`), и надиктованный текст мгновенно напечатается в поле ввода!

### 3. Меню в трее (правый клик по иконке)
* **Открыть историю расшифровок** — удобное окно с перечнем всех последних фраз (можно быстро скопировать текст, если окно случайно потеряло фокус).
* **Скопировать последнюю в буфер** — быстрый хоткей копирования последней фразы.
* **Открыть лог-файл** — текстовый файл `transcriptions.log` со всей историей по времени.
* **Выход** — полное завершение программы.

### 4. Автозагрузка вместе с Windows
1. Нажмите комбинацию клавиш `Win + R`.
2. Введите `shell:startup` и нажмите Enter (откроется папка автозагрузки Windows).
3. Создайте ярлык для файла `start.vbs` и перетащите его в эту папку.

## 🛠️ Установка и запуск на новом компьютере

### Шаг 1. Установка Python
Установите **Python 3.11** (x64) с официального сайта python.org.
> ⚠️ **Важно:** при установке обязательно отметьте галочку **«Add Python to PATH»**.

### Шаг 2. Установка зависимостей
Откройте терминал (PowerShell / CMD) в папке проекта и выполните:
```bash
pip install -r requirements.txt
```
*(Файл `requirements.txt` содержит все нужные библиотеки, включая правильную версию `nvidia-cudnn-cu12==9.1.0.70` для работы на CUDA 12).*

### Шаг 3. Загрузка модели (офлайн)
Чтобы программа не зависела от блокировок Hugging Face в РФ, скачайте файлы модели локально:
1. Создайте папку:
   ```text
   models/large-v3-turbo/
   ```
2. Скачайте 5 файлов по прямым ссылкам с быстрого зеркала:
   * [**`model.bin`**](https://hf-mirror.com/mobiuslabsgmbh/faster-whisper-large-v3-turbo/resolve/main/model.bin) *(1.63 GB — веса модели)*
   * [**`config.json`**](https://hf-mirror.com/mobiuslabsgmbh/faster-whisper-large-v3-turbo/resolve/main/config.json)
   * [**`tokenizer.json`**](https://hf-mirror.com/mobiuslabsgmbh/faster-whisper-large-v3-turbo/resolve/main/tokenizer.json)
   * [**`vocabulary.json`**](https://hf-mirror.com/mobiuslabsgmbh/faster-whisper-large-v3-turbo/resolve/main/vocabulary.json)
   * [**`preprocessor_config.json`**](https://hf-mirror.com/mobiuslabsgmbh/faster-whisper-large-v3-turbo/resolve/main/preprocessor_config.json)
3. Положите их в `models/large-v3-turbo/`. Программа автоматически подхватит их при старте.

## 📊 Выбор модели: что использовать?

| Модель | Размер на диске | Загрузка в VRAM | Потребление VRAM | Скорость (RTF) | Качество (RU) | Рекомендация |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| **`large-v3-turbo`** | **1.6 GB** | **~2–4 сек** | **~1.6 GB** | **0.15–0.25** | **99% (отличное)** | ⭐ **Лучший выбор** (быстрая и точная) |
| **`large-v3`** | 2.9 GB | ~5–8 сек | ~2.7 GB | ~0.40–0.50 | 100% (эталон) | Максимальная точность для сложного сленга |
| **`medium`** | 1.5 GB | ~2–3 сек | ~1.5 GB | ~0.15 | ~95% | Отличная альтернатива для карт с 3–4 ГБ VRAM |
| **`small`** | 480 MB | ~1 сек | ~0.9 GB | ~0.08 | ~85% | Для слабых карт или диктовки простых команд |
| **`base`** | 145 MB | < 1 сек | ~0.5 GB | ~0.04 | ~70% | Быстро, но часто ошибается в окончаниях |

## ⚙️ Настройки (`config.ini`)

Все параметры настраиваются в файле `config.ini`:

```ini
[whisper]
backend = faster
model = large-v3-turbo
device = cuda
compute_type = int8_float32
language = ru
beam_size = 1

[hotkey]
# Клавиша вызова (f9, f10, right_ctrl, scroll_lock, pause и др.)
key = f9

[text]
# Добавлять ли пробел в конце распознанной фразы
add_trailing_space = true

[paste]
# method: unicode (прямая посимвольная печать через SendInput, не затирает буфер обмена) 
# или clipboard (вставка через Ctrl+V)
method = unicode
char_delay = 0.0

[sound]
enabled = true
file = ready.mp3
volume = 0.7
```

## 🔬 Технические особенности реализации

1. **Движок CTranslate2 (`faster-whisper`):**
   * Выполняется на C++ без накладных расходов интерпретатора Python.
   * Квантизация `int8_float32` позволяет запускать тяжелые модели даже на видеокартах с 3–8 ГБ видеопамяти (GTX 1060 / 1070 / RTX 2060+).
2. **Pre-roll Ring Buffer (~250 мс звука):**
   * Аудиопоток непрерывно активен в фоновом кольцевом буфере.
   * Когда вы нажимаете кнопку, скрипт уже содержит последние 250 мс звука до клика, поэтому **первые звуки и слоги никогда не теряются**, даже если вы начали говорить одновременно с нажатием клавиши.
3. **Прямой ввод через WinAPI `SendInput` (Unicode):**
   * В отличие от большинства аналогов, скрипт не использует эмуляцию буфера обмена (`Ctrl+C / Ctrl+V`). Текст вставляется мгновенно напрямую через события Windows API, сохраняя всё, что было скопировано в вашем буфере обмена.
4. **Silero VAD (Voice Activity Detection):**
   * Автоматически отсекает фоновый шум, вздохи и щелчки клавиш, предотвращая галлюцинации Whisper во время тишины.
5. **Универсальный запуск (`start.vbs`):**
   * Автоматически находит интерпретатор `pythonw.exe` через `%LOCALAPPDATA%` на любых пользователях и компьютерах. Запускается в абсолютно скрытом фоновом режиме без всплывающих черных консольных окон.
